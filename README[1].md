# 🛒 EH-Store Website

## یہ کیا ہے؟

یہ آپ کی مکمل EH-Store website ہے! 

## Files میں کیا ہے؟

- `index.html` - Main website page
- `style.css` - Styling (رنگ، ڈیزائن وغیرہ)
- `script.js` - Interactive features
- `favicon.svg` - Website کا لوگو

## Netlify پر Deploy کرنے کے لیے:

### آسان طریقہ:

1. **Netlify کھولیں:** https://netlify.com
2. **Sign Up** (اگر account نہیں ہے)
3. **"Add new site"** → **"Deploy manually"** پر کلک کریں
4. **یہ folder/files** یہاں drag کریں
5. **Upload ہو جائے گا** - بس! ✅

### یا اگر GitHub ہے:

1. GitHub پر اپنا repo بنائیں
2. یہ files upload کریں
3. Netlify میں اپنا GitHub account connect کریں
4. Repo select کریں
5. Auto deploy ہو جائے گا 🚀

## مسائل کی حل:

❌ **Links نہیں کھل رہے؟**
- `index.html` میں `href` links چیک کریں

❌ **تصویریں نہیں دکھ رہی؟**
- یہ placeholder تصویریں ہیں - اپنی تصویریں شامل کریں

❌ **Website slow ہے؟**
- تصویروں کی سائز کم کریں

## اپنی تبدیلیاں کریں:

### Amazon Links تبدیل کریں:
```html
href="https://www.amazon.ae/"  ← یہاں اپنا link ڈالیں
```

### WhatsApp Number تبدیل کریں:
```html
href="https://wa.me/971565308062"  ← اپنا number ڈالیں
```

### تصویریں تبدیل کریں:
```html
<img src="YOUR_IMAGE_URL">  ← اپنی image URL ڈالیں
```
